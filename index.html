1. Create Azure Ubuntu VM

  1. Create a Resource Group.
  2. Create Ubuntu 22.04/24.04 LTS VM.
  3. Select SSH Public Key authentication.
  4. Download the private key (.pem).
  5. Allow inbound ports 22 (SSH) and 80 (HTTP).
  6. Note the Public IP and username.

2. Connect to VM

ssh -i flask-server_key.pem <username>@<VM_PUBLIC_IP>

sudo apt update
sudo apt upgrade -y

sudo apt install -y git curl wget unzip \
python3 python3-pip python3-venv

3. Configure Self-Hosted Runner

# Create folder
mkdir actions-runner
cd actions-runner

# Download runner
curl -o actions-runner-linux-x64-2.336.0.tar.gz -L \
https://github.com/actions/runner/releases/download/v2.336.0/actions-runner-linux-x64-2.336.0.tar.gz

# Validate hash
echo "04cf0be1aff4c3ec3554466c39124ca250e3effd8873bb7e8d68535aa9505d5d actions-runner-linux-x64-2.336.0.tar.gz" | shasum -a 256 -c

# Extract
tar xzf ./actions-runner-linux-x64-2.336.0.tar.gz

4. Register Runner

In GitHub navigate to Repository → Settings → Actions → Runners → New self-hosted runner.

./config.sh \
--url https://github.com/Joy-Marchattiwar/Python-Azure-Actions \
--token <REGISTRATION_TOKEN>

./run.sh
Registration tokens expire quickly. Generate a fresh token whenever you configure a new runner. Do not hard-code or publish tokens.

5. Install Runner as a Service

sudo ./svc.sh install
sudo ./svc.sh start

sudo ./svc.sh status

sudo systemctl status actions.runner*

6. GitHub Actions Workflow

name: Deploy Flask Application

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: self-hosted

    defaults:
      run:
        shell: bash

    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Display Python Version
        run: python3 --version

      - name: Create Virtual Environment
        run: |
          python3 -m venv venv

      - name: Install Dependencies
        run: |
          source venv/bin/activate
          pip install --upgrade pip
          pip install -r requirements.txt

      - name: Stop Existing Flask Process
        run: |
          pkill -f "python.*app.py" || true

      - name: Start Flask Application
        run: |
          sudo systemctl daemon-reload
          sudo systemctl restart flask

      - name: Checking Service Status
        continue-on-error: true
        run: |
          sudo systemctl status flask --no-pager

      - name: Verify Deployment
        run: |
          ps -ef | grep -i "app.py"
